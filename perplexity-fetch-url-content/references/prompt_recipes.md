# Примеры запросов

## Fetch URL Content

- `Используй $perplexity-fetch-url-content, чтобы прочитать "<url>" и вернуть максимум полезного текста с сохранением структуры.`
- `Используй $perplexity-fetch-url-content с --question "<question>", чтобы ответить строго по "<url>".`
- `Используй $perplexity-fetch-url-content, чтобы сравнить детали из "<url A>" и "<url B>" и указать URL, чтение которых не подтвердилось в fetch_url_content.`
